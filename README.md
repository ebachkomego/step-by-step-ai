# 🚶 StepByStep AI — Умный генератор пеших прогулок

Веб-сервис для умного построения пешеходных городских маршрутов на основе желаемого времени, настроения/сценария и вашей геолокации с отрисовкой на **Яндекс Картах** и OpenStreetMap.

---

## 🏛️ Архитектура системы

```
Пользователь (Браузер)
  ├── 1. Запрос геолокации (HTML5 Geolocation API / клик по Яндекс Карте)
  ├── 2. Параметры: время (30-180 мин), сценарий (💖 Свидание, 🏛️ Экскурсия, ☕ Кофе и мысли, 🐕 С собакой), закольцевать (да/нет)
  ▼
Бэкенд (FastAPI, Python 3.11+)
  ├── Модуль Overpass API (Поиск реальных заведений, парков, смотровых площадок в динамическом радиусе)
  ├── Модуль LLM (Google Gemini Flash / OpenAI / Умный Fallback эвристический движок)
  │    └── Защита от галлюцинаций: нейросеть выбирает только из реальных POI
  ├── Модуль OSRM (Построение точной пешеходной GeoJSON геометрии по улицам и тротуарам)
  ▼
Возврат на фронтенд (GeoJSON трека + упорядоченные остановки с описаниями и таймингом)
  ▼
Отрисовка на Яндекс Картах (с привычным дизайном, точными отметками и пешеходной линией)
```

---

## 🗺️ Использование Яндекс Карт

По вашему требованию сервис использует **Яндекс Карты** в качестве основного картографического движка:
- **Узнаваемый и привычный дизайн**: российская детализация, номера домов, входы, скверы и названия улиц.
- **Интерактивные маркеры**: точка старта (зеленая), нумерованные остановки (1, 2, 3...) с карточками-балунами.
- **Точный пешеходный трек**: линия синего цвета прокладывается строго по тротуарам и пешеходным зонам через OSRM API.
- **Интерактивность**: клик в любое место карты моментально переносит точку старта прогулки.
- **Альтернативный слой**: в правом верхнем углу карты доступен переключатель на Leaflet (OpenStreetMap).

## 🚀 Быстрый запуск

### Вариант 1. В один клик (Windows)
Просто запустите файл:
```bat
run_all.bat
```
Скрипт автоматически запустит FastAPI бэкенд на порту 8000 и Vite фронтенд на порту 5173 в отдельных окнах.

---

### Вариант 2. Запуск вручную

#### Бэкенд:
```bash
cd backend
# Активация виртуального окружения (создано)
.\venv\Scripts\activate
# Запуск сервера
python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```
- Swagger UI документация: [http://localhost:8000/docs](http://localhost:8000/docs)
- Проверка работоспособности: [http://localhost:8000/api/health](http://localhost:8000/api/health)

#### Фронтенд:
```bash
cd frontend
npm run dev
```
- Откройте в браузере: [http://localhost:5173](http://localhost:5173)
