# 🚶 StepByStep AI — Умный генератор пеших прогулок

Веб-сервис для умного построения пешеходных маршрутов на **Яндекс Картах** в эстетике **Яндекс Go / Яндекс Карт**.

---

## ✨ Что сделано и как это работает

1. **Только Яндекс Карты (Никаких сторонних или украинских карт):**
   - Полная интеграция с официальным **Яндекс Карты JS API v2.1** на чистом русском языке (`lang=ru_RU`).
   - Все улицы, дома, входы, парки и станции метро отображаются на русском языке в привычном дизайне.
   - Полноценная поддержка **ночной темы для карт** (автоматический dark mode фильтр в стиле Яндекс Навигатора).

2. **Дизайн в стиле Яндекс Go / Яндекс Такси (Без «нейрослопа»):**
   - **Карта во весь экран**: занимает всё пространство, на ней отображается пешеходная геометрия, маркер старта и нумерованные остановки.
   - **Нижняя шторка (Bottom Sheet)**: как в приложении Яндекс Go! Мобильно-адаптивная, легко сдвигается, аккуратная ручка (drag handle).
   - **Простые тарифы/сценарии в 1 клик**:
     - 💖 **Свидание** (романтичные кофейни, виды и аллеи)
     - 🏛️ **Прогулка** (архитектура, памятники, история)
     - ☕ **За кофе** (лучший кофе навынос и уютные скверы)
     - 🐕 **С собакой** (зеленые парки и простор без оживленных дорог)
   - **Чипы времени**: 30 мин, 45 мин, 1 час, 1.5 часа, 2 часа.
   - **Фирменная желтая кнопка**: «Построить маршрут» (`#FFCC00`).

3. **Сайт реально простраивает маршрут:**
   - Строится непрерывная геометрия тротуаров и пешеходных дорожек через OSRM API.
   - Фирменная линия Яндекс красного цвета (`#FC3F1D`) отрисовывается на карте с автоматическим зумом и центрированием.
   - Кнопка «Поехать по маршруту в Яндекс Картах» позволяет сразу открыть маршрут в приложении Яндекс Карт на телефоне.

4. **Автоматическая геолокация с первого захода:**
   - При открытии сайта браузер сразу запрашивает координаты пользователя и ставит стартовую метку прямо на вас.
   - Кнопка 🎯 «Мое место» вверху экрана позволяет быстро центрировать карту на себе.

5. **Темная и светлая тема:**
   - При первом входе тема автоматически определяется по системным настройкам вашего устройства (`prefers-color-scheme`).
   - Кнопка 🌓 в верхнем правом углу переключает тему в один клик.

6. **Никакой головной боли с вводом API-ключей:**
   - Пользователь избавлен от технических настроек: встроен отказоустойчивый интеллектуальный геопространственный движок, который генерирует маршруты сразу из коробки.

## 🚀 Запуск локально

Запустите файл [run_all.bat](file:///d:/хакатон/run_all.bat) в корне проекта:
- Фронтенд: **http://localhost:5173**
- Бэкенд: **http://localhost:8000**
- Swagger API: **http://localhost:8000/docs**

## 🌐 Публикация на GitHub и деплой на Vercel

### 1. Отправка на GitHub (`ebachkomego`):
1. Откройте [https://github.com/new](https://github.com/new) и создайте репозиторий с названием:
   ```
   step-by-step-ai
   ```
2. Запустите готовый скрипт:
   ```bat
   push_github.bat
   ```
   *(Или выполните в терминале: `git push -u origin main`). Все коммиты уже сформированы!*

### 2. Деплой на Vercel:
В проект уже добавлен файл `vercel.json` с конфигурацией сборки Frontend + Python Serverless:
1. Зайдите на [vercel.com](https://vercel.com) под своим аккаунтом.
2. Нажмите **Add New... -> Project**.
3. Выберите ваш репозиторий `ebachkomego/step-by-step-ai`.
4. Нажмите кнопку **Deploy**! Vercel автоматически соберет проект и выдаст ссылку на рабочий сайт вида `https://step-by-step-ai-*.vercel.app`.
